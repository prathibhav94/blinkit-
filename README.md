# Blinkit Grocery Data Analysis Dashboard

## Project Overview

This project is a **Blinkit Grocery Data Analysis Dashboard** created using **Microsoft Power BI**.

The main purpose of this project is to analyze grocery sales data and understand the performance of different products, outlets, outlet locations, outlet sizes, and outlet types.

The dashboard converts raw sales data into useful visual reports and KPIs that can help in understanding business performance and making better decisions.

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning
* Data Visualization
* Data Analysis

## Key Performance Indicators (KPIs)

The dashboard shows the following important KPIs:

* **Total Sales:** $1.20M
* **Average Sales:** $141
* **Number of Items:** 8,523
* **Average Rating:** 3.9

These KPIs provide a quick overview of the overall business performance.

## Dashboard Analysis

The dashboard contains different charts and visualizations to analyze the grocery sales data.

### 1. Sales Analysis

The dashboard shows total sales and average sales to understand the overall sales performance.

It also shows sales trends based on the outlet establishment year, helping to understand how sales have changed over time.

### 2. Item Type Analysis

The dashboard provides sales information for different item categories such as:

* Fruits and Vegetables
* Snack Foods
* Household Items
* Frozen Foods
* Dairy
* Canned Items
* Baking Goods
* Health and Hygiene
* Meat
* Soft Drinks
* Breads
* Others

This helps identify which product categories contribute more to total sales.

### 3. Fat Content Analysis

The dashboard compares products based on their fat content, such as:

* Low Fat
* Regular

This helps understand the contribution of different fat-content categories to total sales.

### 4. Outlet Size Analysis

The dashboard analyzes sales based on outlet size:

* Small
* Medium
* High

This helps compare the performance of outlets of different sizes.

### 5. Outlet Location Analysis

The dashboard compares outlet performance across different location tiers:

* Tier 1
* Tier 2
* Tier 3

This helps identify which outlet locations generate higher sales.

### 6. Outlet Type Analysis

The dashboard compares different types of outlets, including:

* Supermarket Type 1
* Supermarket Type 2
* Supermarket Type 3
* Grocery Store

The analysis includes metrics such as total sales, number of items, average sales, average rating, and item visibility.

## Filters Used

The dashboard includes filters to make the analysis interactive.

Users can filter the data based on:

* Outlet Location Type
* Outlet Size
* Item Type

These filters allow users to view specific parts of the data and analyze the business from different perspectives.
